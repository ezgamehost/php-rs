Implementation:
- getenv/putenv with request-local state, preserving the host process environment.
- Enumeration filters malformed names while direct lookups retain their values.
- Reassignment restores the original entry before replacing it, matching native
  environment enumeration order.
- INI interpolation, sys_get_temp_dir, tempnam/tmpfile fallback and temporary
  stream spill use the request's environment and cached temporary directory.
- Isolated PHPT ENV handling for workers, reference checks and CLEAN, including
  absolute {PWD} expansion, duplicate assignment replacement and native trimming.
  Ordinary library parsing continues to report ENV as unsupported.
- Native reflection metadata now covers 429 implemented function names.

Remaining limits:
- This CLI runtime has no separate web SAPI environment; local_only selects the
  same request environment.
- Windows-specific environment-name/code-page behavior remains unfinished.
- Configuration-directive lookup for INI interpolation and other unsupported
  PHPT sections remain unfinished.
- The broader PHP 8.5 runtime remains incomplete, including subprocess APIs.
