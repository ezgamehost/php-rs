- Exact native PHP 8.5.0 comparisons cover binding, independent static storage,
  Closure-method first-class callables and their identity, clone behavior,
  class metadata, synthetic __invoke signatures, reflection-held lifetimes,
  serialization restrictions, weak call coercion under strict_types,
  callable-resolution errors, and reflective invocation with references.
- No new tests, upstream fixture changes, or dependencies.

Implementation:
- Registered the internal final Closure class and its six declared methods.
  Direct instantiation and reflection without construction are prohibited.
- Implemented bind, bindTo, and call with native scope/receiver validation,
  PHP 9 transition warnings, captured references, separate bound static storage,
  and weak internal-call coercion. Calls preserve the original closure state.
- Implemented fromCallable using caller scope/object resolution, native error
  wording, existing-closure identity, and method/first-class callable conversion.
  getCurrent returns the active anonymous closure and rejects ordinary functions
  and first-class callables wrapping named functions.
- Closure method receivers are represented separately from the invoked closure,
  preserving identity and receiver lifetime through first-class callables.
- ReflectionClass/ReflectionObject accept closure values. Synthetic __invoke
  methods expose actual parameter and return metadata and support reflective
  invocation, argument arrays, parameter reflection, and getClosure identity.

Remaining limits:
- Binding a Closure value as $this remains unsupported; ordinary object receivers
  work. Complete closure debug output, some synthetic-method declaration strings,
  and closure-specific type/default reflection still need work.
- Generator closures and closure-cycle collection remain incomplete. This focused
  gate does not establish full PHP conformance.
