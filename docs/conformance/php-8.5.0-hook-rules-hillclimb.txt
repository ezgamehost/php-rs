- Direct PHP 8.5.0 comparisons confirm final-check precedence, inherited static
  owner names, trait conflicts, permitted trait override of inherited properties,
  getter side effects/exceptions during reference assignment, and canonical
  setter-type diagnostics. CLI comparisons ignore the existing leading blank-line

  Existing Rust tests confirm retained fatal messages remain API errors.
- No new tests or upstream fixture changes; no dependencies added.

Implementation:
- Final-property checks precede hook merging and include static/instance
  redeclarations. Diagnostics name the original declaring class. Final/private
  combinations are rejected for ordinary and promoted properties.
- Hooked-property collisions between a class and its traits, or between traits,
  produce the native composition error. Inherited properties remain eligible
  for ordinary trait overrides; they are not local composition conflicts.
- Reference assignment invokes an available getter before reporting an overloaded
  target. Getter exceptions propagate. Missing getters retain write-only and
  indirect-modification errors instead of using the overloaded-target error.
- Abstract setter compatibility diagnostics use PHP's canonical union ordering.
- Class-linking compile errors emit a fatal and unwind without PHP exception
  handling. A retained diagnostic remains an error at the Rust execution API
  boundary; ordinary exit signals continue returning normally. Reporting an
  already emitted fatal does not duplicate it or call an exception handler.

Remaining limits:
- Hook attributes, full hook reflection, generator hooks, complex interface
  merges, and AST rendering remain unfinished. This is a focused gate, not
  full PHP conformance.
