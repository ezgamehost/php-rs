- cargo clippy --locked --all-targets -- -D warnings
- cargo test --locked: all 797 existing Rust tests pass
- cargo build --locked --bins
- project PHPT: all 57 pass
- cargo fmt --check; git diff --check
- Direct PHP 8.5.0 comparisons match setter coercion and assignment results,
  ordinary members after hooks, lazy-proxy call order, dynamic self-access to
  virtual properties, backing-reference access, and reference/unset errors.
- No new tests or upstream fixture changes; no dependencies added.

Implementation:
- Concrete get/set hooks parse block and short bodies, reference getters and
  explicit setter parameters. Short setters assign their expression to backing
  storage; short getters return it. Existing target validation and constant
  folding traverse hook bodies. __PROPERTY__ follows the lexical hook scope.
- Backing-storage detection traverses the unoptimized hook body, excluding nested
  functions and classes. Virtual properties do not allocate default slots.
- Runtime property reads/writes invoke hooks with the declaring class scope.
  Access in the active hook reaches backing storage for the same object,
  including an initialized lazy proxy instance. Virtual self-access throws.
- Inheritance merges missing hooks and retains inherited backing storage;
  trait composition rebinds hook scope. Final hook overrides are rejected.
- Hooked reference assignment, indirect mutation, unset, readonly/static hooks,
  duplicate/unknown hooks and invalid setter parameter forms report errors.
- Reflection exposes hasHooks/isVirtual and virtual default-value availability;
  traces retain the property name in hook frames.

Remaining limits:
- Abstract/interface hooks, promoted hooks, parent-hook calls and full hook
  type variance and attribute validation are unfinished.
- Full hook reflection, hook-aware foreach/get_object_vars/JSON/property export,
  and remaining inheritance/diagnostic edge cases are unfinished.
- Generators, unsupported PHPT sections, and the broader PHP 8.5 runtime remain
  incomplete. This is a concrete-hook implementation slice, not full conformance.
