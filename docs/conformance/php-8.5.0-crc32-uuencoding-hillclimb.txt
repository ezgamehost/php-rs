crc32 uses the reflected AUTODIN II polynomial and a compile-time lookup table,
with native initialization/final inversion. Its result is a nonnegative integer
under this runtime's 64-bit PHP integer model. All 256 generated table entries
match PHP's crc32.h. The 32-bit-only CRC32 fixtures remain unsupported and are
not counted as passes.
convert_uuencode emits 45-byte lines, padded six-bit groups, and the native
backtick/newline terminator. convert_uudecode preserves six-bit byte conversion,
short-line and zero-header termination, unvalidated line separators, trailing
input handling, declared-length truncation and malformed-input warnings. Bounds
checks reject truncated groups without reading outside the input.

Direct PHP reference comparisons match empty/binary inputs, all byte values,
a one-MiB CRC32 input, encoding lengths around 3-byte and 45-byte boundaries,
partial/missing terminators, noncanonical encoded bytes, malformed lengths,
weak/strict arguments, named parameters, Stringable conversion and warning
handler exceptions. The existing out-of-bounds regression bug67252 passes.
PHP's invalid-encoding diagnostic intentionally says data, while the parameter
name exposed to named calls and reflection is string.
The Berkeley uuencode/uudecode license and acknowledgement are retained in
THIRD_PARTY_NOTICES.md and README.md.
