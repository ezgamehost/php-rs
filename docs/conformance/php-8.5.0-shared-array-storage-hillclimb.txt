All 8,267 fixture statuses are retained: 4,203 passed, 3,204 failed,
860 unsupported. This slice resolves the captured-child-array limitation from
60da102; it does not claim new full-suite passes or complete PHP conformance.

PhpArray now wraps its hash-table data in RefCell. Normal Rc::make_mut writes
still duplicate array storage. Native RecursiveArrayIterator child writes use
checked shared mutation, so captured aliases and the parent observe the same
changes. Parent and child hold the same Rc table instead of linking the parent
bucket to an indirect child-storage cell. Ordinary writes, repeated children,
constructor reentry, and sorting retain their separation behavior.

The same checked storage removes the unsafe shared-Rc writes from array_splice.
Mutation closures execute no PHP; reads crossing callbacks take an owned current
entry and release the table borrow. Weak read cursors adjust for removed buckets
without retaining the rest of the values. Copies that inspect PHP reference
ownership use copy_array_entry before introducing temporary Rust reference owners.
The Rust PhpArray API now returns an owned Value from get and a Ref guard from
entries; callers that execute PHP use owned entry reads instead of that guard.

Validation:
- 797 existing Rust tests pass (cargo test --locked).
- 57 project PHPT fixtures pass against Rust and the PHP 8.5.0 reference.
- All 35 upstream fixtures that regressed during development pass again.
- Six final full suites compare to the pushed baseline with zero regressions.
- cargo fmt --all -- --check, Clippy with -D warnings, and git diff --check pass.
- No new custom tests or generated differential matrices were added.

Direct CLI reference comparisons also match captured copies, parent separation,
repeated children, constructor reentry, sorting, native nested writes and offset
references, unset, foreach mutation, array_map mutation, and __debugInfo mutation.
These probes supplement the upstream suites and do not add to the pass counts.

Remaining work includes RecursiveIteratorIterator and other SPL classes,
serialization, physical bucket/cursor edge cases, and previously recorded runtime
and harness gaps. Mutation of input arrays during sorted-set callbacks is not
claimed as complete by this slice.
