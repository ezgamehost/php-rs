Implements ReflectionClass/ReflectionObject declaration strings for classes,
interfaces, traits, enums and objects. Rendering includes declaration comments,
source ranges, modifiers, extension ownership, implemented interfaces, enum
cases/backing values, constants, static/instance properties and methods, inherited
member flags and dynamic property names. Inherited private members are filtered;
properties display declaration defaults rather than current values. Constants,
properties and methods reuse their standalone formatters with structural indentation,
preserving embedded newlines in comments and constant values. Rendering does not
allocate temporary reflector objects or expose dynamic property values.

Class documentation and extension queries are exposed. The parser retains class
and promoted-property comments. Native class/interface extension ownership is
extracted from PHP 8.5.0; builtin method reflection uses its declaring class's
module, and user-enum methods correctly have no extension. Enum interfaces follow
explicit declarations before UnitEnum/BackedEnum. Interface enumeration preserves
PHP's different inheritance-only and explicit-implements ordering, including
reversed linked parent tables. Class-name qualification in constant defaults
preserves unqualified references while callable defaults remain fully qualified.
Implicit-nullability diagnostics use qualified method names.

The generated class_modules.rs contains 165 reference class/interface mappings;
it supplies metadata only for classes that the runtime actually implements.
Ownership matches the reference for all 105 currently reflectable native classes
and interfaces. Regeneration is byte-identical after rustfmt, SHA256:

Direct comparisons also cover multiline documentation and binary constant values,
private/inherited/static/dynamic members, changed property values, enum objects,
readonly/promoted properties, interface diamonds and inherited ordering, class
attributes/comments and symbolic/callable default qualification.

Complete internal class layouts/method signatures, Reflector interfaces, property
hooks and closure-object reflection remain incomplete. In particular, the large
ReflectionClass self-rendering fixture still exposes missing lazy-object methods
and native tentative return metadata. Existing parser/default-expression limitations
remain. PHP/Zend source
attribution is retained in THIRD_PARTY_NOTICES.md.
