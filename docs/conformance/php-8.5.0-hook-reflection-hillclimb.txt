- Direct PHP 8.5.0 comparisons cover reflective hook closures, inherited hook

  final-hook metadata, setter types, and hook parameter magic constants.

Implementation:
- Hook attributes retain declaration context and custom setter parameter context.
  Override checks inherited hooks and implicit backing operations. NoDiscard is
  rejected on hooks, or deferred to ReflectionAttribute::newInstance when requested.
- PropertyHookType is a native backed enum. ReflectionProperty exposes hook methods,
  raw access, setter input types, virtual initialization state, modifier flags,
  and declaration strings including final accessors.
- Hook ReflectionMethod objects retain complete names, declaration scopes,
  attributes, final flags, and inherited prototypes. Reflective invocation and
  closures enter the same backing-storage guard as ordinary hook dispatch.
- Raw property operations select the effective declaration for the supplied object
  and substitute internal accessors when the requested hook exists. Missing hooks
  preserve ordinary access semantics, including virtual-property diagnostics.
- Raw setters initialize lazy objects unless explicitly bypassed. Parent implicit
  setters share this initialization behavior; bypassed writes realize only their
  target slot. Getter/setter bodies are not called by raw access.
- Class strings mark hooked-property iteration support while isIterable retains
  its separate Traversable contract.

Remaining limits:
- Generator hooks, complex interface merges, initializer expressions, and complete
  AST rendering remain unfinished. This focused gate does not establish full PHP
  conformance; 2,176 failures and 1,456 unsupported fixtures remain in these suites.
