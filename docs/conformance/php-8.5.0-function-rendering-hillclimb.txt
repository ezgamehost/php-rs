Implements ReflectionFunction, ReflectionMethod and ReflectionParameter string
rendering, with source locations, documentation comments, optional/required and
variadic/reference markers, default expressions, canonical union/iterable type
ordering, return types, deprecation/extension labels, closure captures and static
locals, and method inheritance/override/prototype/constructor flags. Method-based
closures preserve PHP's visibility rendering. Function and method documentation
comments are retained by the parser and exposed through getDocComment().
Function extension queries and method prototype queries are also supported,
including abstract/interface constructor prototypes retained through concrete
intermediate implementations. Reflectors with __toString implement Stringable.

Generated metadata covers the 417 currently implemented native function names.
It supplies reflection parameter names/types, exact symbolic default expressions,
return types, extension ownership, SensitiveParameter attributes and native
by-reference/value modes. Omitted-default sentinels stay distinct from null
and do not create implicit nullable types. Native invocation retains its own
binding/coercion path. Parsed metadata is cached per thread; runtime execution
has no PHP binary dependency.

tools/generate_native_signatures.py extracts metadata from a PHP 8.5.0 binary.
Regeneration is byte-identical after rustfmt, SHA256:

including names, return types, required counts, optional/variadic/reference flags,
nullability, default-value availability, symbolic constant names, serialized default
values and parameter attribute names. Direct comparisons also cover userland
function/method documentation, closures and bound variables, callable defaults,
constant-expression syntax/precedence, namespace-qualified names, canonical type
ordering, method callables and inherited constructor prototypes.
