- cargo clippy --locked --all-targets -- -D warnings
- cargo test --locked: all 797 existing Rust tests pass
- cargo build --locked --bins
- project PHPT: all 57 pass
- cargo fmt --check; git diff --check
- PHP 8.5.0 comparisons confirm duplicate-interface abstract requirements count
  once and overlapping setter/property type unions autoload each name once.
- No new tests or upstream fixture changes; no dependencies added.

Implementation:
- Abstract properties and interface hook declarations retain separate property
  and accessor flags. Invalid modifiers, bodies, and missing abstract hooks are
  diagnosed without treating accessors as ordinary methods.
- Concrete backing storage satisfies abstract getters and writable setters.
  Missing accessors retain their original declaration and abstract requirement.
  Readonly properties satisfy getter-only requirements.
- Class/interface validation checks accessor signatures, reference getters,
  property visibility and set visibility. Shared interface requirements count
  once, and missing-method diagnostics list ordinary methods before accessors.
- Virtual getter-only properties are covariant and setter-only properties are
  contravariant; backed and bidirectional properties remain invariant.
- Explicit setters must accept the property type. Unresolved class types defer
  early linking and invoke autoloaders before compatibility is checked again.
- Abstract setters implemented by plain properties constrain the writable type.
- Reflection exposes abstract property flags. Existing property Override checks
  can now inspect interface property declarations.

Remaining limits:
- Complex merges of conflicting interface property declarations, complete
  inherited-interface reflection, intersection/DNF types, and some diagnostic
  and class-linking edge cases remain unfinished.
- Promoted hooks, parent-hook calls, hook attributes/full reflection, and
  hook-aware enumeration/export remain unfinished.
- Generators, unsupported PHPT sections, and the broader PHP runtime remain
  incomplete. This report covers the listed regression gate only.
