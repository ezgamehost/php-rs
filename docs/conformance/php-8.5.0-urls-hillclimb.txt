parse_url follows PHP's scheme/port ambiguity, relative authority, credentials,
last-@ and last-colon handling, bracketed host treatment, file drive paths,
empty-versus-absent path/query/fragment components, control-byte replacement,
port range/length rules and native strtol permissiveness. Invalid URLs return
false before component-identifier validation; negative identifiers return the
whole component array, preserving PHP's field ordering. PHP_URL_* component
constants and PHP_QUERY_RFC* constants are exposed with standard metadata.
urlencode/urldecode and rawurlencode/rawurldecode operate on arbitrary bytes,
with uppercase hex escapes, native safe-character sets, space/plus and tilde
rules, preserved malformed escapes and binary-safe decoded NUL handling.

Direct PHP comparisons match representative URL structures and errors, component
selection/defaults, every byte value in percent codecs, malformed escapes,
weak/strict and named argument handling, Stringable input and constant metadata.
A further 17,381 generated parsing cases match PHP exactly, including exhaustive
short combinations and deterministic structured inputs with control/high bytes.

json_encode, getenv/CLI-server support or get_defined_constants; its EXTENSIONS
