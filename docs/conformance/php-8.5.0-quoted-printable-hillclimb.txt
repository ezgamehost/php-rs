quoted_printable_encode follows PHP's byte escaping and line wrapping, including
preserved CRLF, encoded lone CR/LF, control and high bytes, spaces before CR,
and the UTF-8 byte-range lookahead used when inserting soft breaks. Continuation
bytes participate in that native rule; bytes above F4 do not themselves trigger
wrapping. Output allocation uses checked size arithmetic and a fallible reserve.
quoted_printable_decode recognizes hexadecimal escapes and permissive soft line
breaks, including spaces/tabs after equals and CR/LF/CRLF. It retains invalid hex
escapes, drops a terminal equals and its following spaces/tabs, and stops at an
input NUL. Decoded =00 bytes remain in the result and do not terminate decoding.
The public decoder follows the PHP function, not its stricter internal helper.

Direct PHP reference comparisons match every byte value, repeated binary data,
empty input, NUL handling, malformed/truncated escapes, line-length boundaries,
UTF-8 byte classes and multi-byte text, trailing whitespace, weak/strict argument
conversion, named parameters and Stringable input. Both existing regression
fixtures pass, including the output-allocation regression for repeated F4 bytes.
