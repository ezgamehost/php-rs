Validation:
- cargo build --locked --bins
- cargo clippy --locked --all-targets -- -D warnings
- cargo test --locked: all 797 existing Rust tests pass
- project PHPT: all 57 pass
- cargo fmt --check; git diff --check
- Direct PHP 8.5.0 comparisons match for mutations/removal of later declared
  properties, dynamic-property snapshots, decoded object identities, numeric keys,
  flag precedence, error persistence, deep validation, and callback exceptions.
- No new test files or upstream fixture changes; no new dependencies.

Implementation:
- json_encode, json_decode, json_validate, json_last_error and json_last_error_msg.
- JSON constants and JsonException, including native exception codes and traces.
- Formatting, escaping, UTF-8 handling, surrogate pairs, associative objects,
  large integers, numeric strings, pretty printing and preserved zero fractions.
- Array/object recursion, depth errors, partial output and exception-state rules.
- JsonSerializable hooks, self-returning callbacks, enums, lazy objects, SPL
  storage, live declared properties and snapshots of dynamic properties.
- Iterative parsing/validation; validation avoids constructing decoded containers.
- Native reflection metadata now covers 425 implemented function names.

Remaining limits:
- Configurable serialization precision and property hooks remain unfinished.
- Encoding caps native traversal at 1,024 container levels rather than querying
  PHP's configurable host-stack limit.
- Fourteen JSON fixtures require currently unsupported INI/SKIPIF handling.
- Other runtime failures and unsupported fixtures remain as recorded. This is a
  conformance increment, not completion of PHP 8.5 compatibility.
