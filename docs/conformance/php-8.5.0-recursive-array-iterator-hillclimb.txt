RecursiveArrayIterator extends ArrayIterator and implements RecursiveIterator.
CHILD_ARRAYS_ONLY filters object children. hasChildren reads native current data;
getChildren handles the end position, reuses objects of the same class/subclass,
and otherwise invokes the same subclass constructor with the entry and flags.
Scalar entries reach the inherited constructor's type error. Native constructor
calls have internal frames; failed child construction runs the child destructor.

Array children link their native storage to the parent's entry. Direct child
writes propagate through this internal link. Parent-side nested writes detach the
entry; repeated child creation replaces the link. Sorting a child separates its
result from the parent, and constructor reentry reconnects array storage. Weak
parent/child metadata avoids retaining parents. Destructor transfer refreshes
child-slot lookup. These internal links do not become PHP reference containers.

All 797 existing Rust tests and 57 reference-checked project PHPT pass.
Formatting, Clippy, and diff checks pass. No custom tests or matrices added.
Direct PHP CLI checks match child/parent writes, repeated children, constructor
reentry, sorting detachment, subclass constructor invocation, scalar error traces,
and constructor-failure destruction. Reference diagnostic settings:
 display_errors=stderr and log_errors=0.
