- Direct PHP 8.5.0 comparisons match for reference getters, trait parent scope,
  lazy backing access, setter coercion, and unpacked/named arguments.
  Nested closure rejection matches PHP's fatal diagnostic, apart from the CLI's
  existing leading blank-line difference.
- No new tests or upstream fixture changes; no dependencies added.

Implementation:
- Literal, unparenthesized parent::$prop::get/set calls are recognized separately
  from dynamic static calls. Hook names are case-insensitive. Compile checks
  require the matching property/accessor context and prohibit closure conversion.
- Parent lookup uses the executing hook's declaration scope, preserving inherited
  hooks and trait rebinding. Missing parents/properties and private properties
  produce PHP's runtime errors.
- User-defined parent accessors use ordinary argument binding and hook frames,
  retaining reference returns and allowing extra positional arguments.
- Plain parent properties use internal accessor functions with strict arity and
  named-argument checks. The shared property path accesses backing storage,
  including lazy initialization, typed slots, and assignment coercion.
- Existing dump, export, default-value inheritance, and multi-level-inheritance
  fixtures now pass through their parent calls.

Remaining limits:
- Promoted hooks, hook attributes and full hook reflection remain unfinished.
- Complex interface merges, generator hooks, final-property diagnostics, and
  some indirect-access cases remain incomplete. This is a focused gate, not
  full PHP conformance.
