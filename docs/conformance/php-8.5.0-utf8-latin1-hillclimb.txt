utf8_encode maps each Latin-1 byte to its corresponding Unicode code point.
utf8_decode returns Latin-1 bytes and replaces non-Latin-1 characters or illegal
UTF-8 sequences with question marks. The shared UTF-8 reader follows PHP's
consumption of malformed sequences: it preserves a subsequent ASCII or valid
leading byte for the next iteration, consumes other invalid bytes within the
current sequence's expected width, and rejects overlong forms, surrogate values
and code points above U+10FFFF. NUL is ordinary data in both conversions.

Deprecation uses the existing call-attribute diagnostic path, before native
arity/type checks. The same native metadata drives ReflectionFunction's
isDeprecated and getAttributes, including attribute arguments, filtering and
instantiation. assert_options and lcg_value retain their diagnostics and now
expose their existing Deprecated metadata through the same reflection path.

Direct PHP comparisons match Latin-1 roundtrips, malformed and truncated UTF-8,
non-Latin-1 characters, binary inputs, weak/strict and named arguments,
Stringable conversion, invalid arity, unknown named parameters, throwing
handlers and their traces, array_map/call_user_func/reflection/closure calls,
and native Deprecated reflection. A further 90,101 byte-sequence comparisons
match exactly: all two-byte inputs and selected four-byte combinations covering
valid/invalid leading and continuation byte classes.
