Implementation:
- Duplicate access, static, abstract, final, and readonly modifiers produce
  native CompileError diagnostics, including class and trait adaptation paths.
  Invalid abstract/final and readonly method/constant combinations preserve
  catchability inside eval.
- Invalid abstract and interface method declarations, missing concrete bodies,
  unexpected abstract bodies, and abstract constructor promotion produce fatal
  compile diagnostics. Class, enum, and anonymous-class wording is retained.
- Parser-detected fatal declarations carry an unwind signal to the source-loading
  boundary, which materializes a deferred CompileError diagnostic. This preserves
  the Rust API's output boundary while bypassing PHP catches and finally blocks.
  Ordinary syntax errors and catchable compile errors retain their existing flow.

  behavior remain incomplete. This focused gate does not establish full PHP
  conformance.
