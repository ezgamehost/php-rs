Traversable, Iterator, and IteratorAggregate expose native inheritance and
interface method metadata, including tentative returns and ReturnTypeWillChange.
Concrete Traversable classes require Iterator or IteratorAggregate; implementing
both is forbidden. Abstract Traversable classes and derived interfaces are allowed.
User foreach recursively resolves aggregates and invokes rewind/valid/current/key/
next with internal callback trace sites. It fetches keys only when requested,
retains current results across the loop body, preserves references until value
assignment, and propagates exceptions and loop control. Invalid aggregate returns,
including self-return, raise Exception. Iterating a user Iterator by reference
raises Error. Temporary aggregates are destroyed after initial rewind/valid,
while their resolved iterators remain alive. Nested aggregate temporaries and
callback results drain queued destructors at the relevant boundaries.

Iterable type declarations, is_iterable, and ReflectionClass::isIterable and
isIterateable recognize objects implementing Traversable without invoking them.
Reflection includes concrete enums with iterator interfaces.
