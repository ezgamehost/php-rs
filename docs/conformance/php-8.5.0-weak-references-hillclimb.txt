Implementation:
- Add the final native WeakReference class with create/get and PHP's constructor,
  dynamic-property, cloning, serialization, and constructor-bypass restrictions.
- Each PHP object handle owns an identity token that moves with it through the
  destructor queue. Weak references resolve that token through the object store,
  preserving resurrection while rejecting reused numeric handles.
- Closures use weak closure pointers. Neither kind of target is kept alive by
  its wrapper. Repeated creation shares a live wrapper; dropping the wrapper
  removes its weak cache entry.
- Debug properties expose the current target without adding ordinary properties
  or affecting casts, JSON, get_object_vars, or property_exists.
- Extending a final class is a compile fatal, rather than a catchable Error.

Remaining limits:
- WeakMap, debug_zval_dump, get_declared_classes, and broader cycle-collection
  behavior remain unfinished. The basic weakrefs_001 fixture still needs
  debug_zval_dump. This focused gate does not establish full PHP conformance.
