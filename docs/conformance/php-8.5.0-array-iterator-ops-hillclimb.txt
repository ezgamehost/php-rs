Six-suite improvement: one new SPL pass, zero regressions.
The new pass is ArrayObject/arrayIterator_ksort_basic1.phpt.

ArrayIterator implements asort, ksort, uasort, uksort, natsort, and natcasesort via
existing native array sort functions. Callback validation and errors have the
underlying function's internal frame. Sort guards are object-local, reject writes,
direct removals, and writable offset references, and are released after errors.
Nested unsets retain PHP's BP_VAR_UNSET exception. The result table is installed
even after a comparison exception; reentrant construction preserves the storage
slot and active guard. Object-backed sorts preserve reordered ordinary properties
in snapshots and clones.

ARRAY_AS_PROPS routes reads, writes, isset/empty, unsets, references, and nested
operations to offsets when there is no accessible initialized ordinary property.
Offset overrides participate; ordinary initialized properties retain priority.
property_exists distinguishes existing null slots and handles inherited offset
hooks. Uninitialized/inaccessible declared slots may fall through to array data.

All 797 existing Rust tests and 57 reference-checked project PHPT pass.
Formatting, Clippy, and diff checks pass. No custom tests or matrices added.
Direct PHP CLI probes match output and exit status for all six sorts, callback
error traces and recovery, mutation guards and nested unsets, constructor reentry,
object backing order/clones, property references, visibility/uninitialized slots,
null queries, and offset/magic overrides with flag changes. Reference diagnostic
settings: display_errors=stderr and log_errors=0.

Final logs: /tmp/php-rs-array-iterator-ops-{suite}3.log, tests3.log, project3.log,
and clippy3.log. Intermediate runs informed fixes; only final full-suite results

Implementation source: PHP 8.5.0 ext/spl/spl_array.c and spl_array.stub.php,
using the existing native array sort, reference, and property infrastructure.

Remaining gaps include serialization/Serializable, native object comparison,
disabled functions, precise overloaded-object rejection, and cursor/diagnostic
edges. ArrayObject and RecursiveArrayIterator remain unimplemented; prior runtime
and PHPT-harness limitations remain. Unsupported sections are not passes.
