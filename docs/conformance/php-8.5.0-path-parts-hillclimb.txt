IMPLEMENTATION AND LIMITS
basename strips trailing slashes and returns the last component, removing a suffix
only when it is shorter than the component. dirname strips the final component and
its adjacent separators, preserving internal bytes and avoiding normalization.
Multiple levels stop when the output no longer shortens. pathinfo returns an array
only for flags exactly equal to PATHINFO_ALL; other combinations return the first
available requested component. Its dirname insertion uses native C-string behavior.
PATHINFO_DIRNAME/BASENAME/EXTENSION/FILENAME/ALL have standard-extension metadata;
pathinfo's reflected flags default retains the PATHINFO_ALL constant expression.
Windows paths, non-ASCII-compatible locales, PHP memory limits, and allocation-failure
diagnostics remain unfinished. PHP 8.5.0 ext/standard/string.c and Zend/zend_compile.c,
native signatures, upstream PHPT, and reference execution establish behavior.
