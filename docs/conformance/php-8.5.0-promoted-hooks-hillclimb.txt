- Direct PHP 8.5.0 comparisons match implicit-promotion attributes and defaults,
  parent accessor dispatch, and trait promotion. Rejection of hooks outside
  constructors and on readonly properties matches the fatal diagnostics, apart
  from the CLI's existing leading blank-line difference.
- No new tests or upstream fixture changes; no dependencies added.

Implementation:
- Constructor parameters retain parsed property hooks in promotion metadata.
  Hook-only parameters imply public promotion. Hook parsing shares normal
  property type, visibility, lexical scope, and backing-storage detection.
- Promoted property construction uses one declaration path for hook parsing
  and final class properties. Existing constructor-entry assignments invoke
  setters before the constructor body.
- Parameter defaults remain separate from property defaults. Untyped backed
  properties receive implicit null storage; virtual properties have no slot.
- Attribute validation waits until promotion is known, retaining property and
  parameter targets even when visibility is omitted. Readonly hooked properties
  and hooks outside constructors are rejected.

Remaining limits:
- Hook attributes and full hook reflection remain unfinished.
- Complex interface merges, generator hooks, final-property diagnostics, and
  some indirect-access cases remain incomplete. This is a focused gate, not
  full PHP conformance.
