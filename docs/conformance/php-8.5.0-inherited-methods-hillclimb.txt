Implementation:
- Inherited method and interface compatibility failures use deferred compile
  fatals, retaining the original method source and line. Final, staticness,
  abstractness, and visibility checks use native ordering and diagnostics.
  At the public execution boundary the unwind becomes ErrorKind::Error,
  preserving the embedding API while retaining the native CompileError payload
  and bypassing registered exception handlers.

  returns, and defaults. Strings abbreviate after ten bytes; array and constant
  defaults retain their native representations. Defaults before required
  parameters are omitted from declaration signatures.
- Abstract-member completeness reports counts and up to three named methods,
  with native anonymous-class and enum wording. Missing property hooks retain
  priority over ordinary property redeclaration errors.
