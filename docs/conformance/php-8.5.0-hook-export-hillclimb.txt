- Direct PHP 8.5.0 comparisons confirm virtual-property dumps, export guard
  cleanup after getter exceptions, and declared/dynamic mutation order.
  Recursive getter export matches PHP's warning and values, apart from the
  CLI's existing leading blank-line difference for the warning.
- No new tests or upstream fixture changes; no dependencies added.

Implementation:
- foreach visits accessible declared properties before live dynamic entries.
  Getters supply values; reference iteration requires reference getters and
  preserves returned aliases. Virtual write-only and uninitialized backed slots
  are skipped. Iterator-held values survive the body before destructor draining.
- get_object_vars, JSON, and var_export read getters as entries are consumed.
  Declared slots stay live, including slots initialized by earlier callbacks;
  dynamic values retain the snapshot from before callbacks. Visibility filtering
  precedes getter invocation. Private export reads use declaration scope.
- var_export shares recursion guards across nested callbacks and clears guards
  after errors; guards are installed before lazy initialization.
- Virtual properties have no class defaults or debug-dump backing slots.
  Unserialization rejects values for virtual properties before parsing the value,
  preserving PHP's warning and failure offset. Array casts and serialization
  continue to use backing values without invoking getters.

Remaining limits:
- Parent-hook calls still block dump and multi-level-inheritance fixtures.
- Promoted hooks, hook attributes and full hook reflection remain unfinished.
- Complex interface merges, generator hooks, and some indirect-access cases
  remain incomplete. This is a focused gate, not full PHP conformance.
