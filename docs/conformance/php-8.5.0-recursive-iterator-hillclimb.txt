Native RecursiveIteratorIterator now implements OuterIterator with all three
traversal modes, CATCH_GET_CHILD, and depth bounds. Its state machine preserves
child detection, descent, self visitation, ascent, and next-element ordering.
User overrides of the Iterator methods select user iteration; otherwise native
iteration drives the traversal directly. Optional recursive hooks retain their
own PHP callback frames and state transitions. Child error catching excludes
fatal exit/unwind and follows the native branch-specific behavior.

Construction accepts RecursiveIterator or one IteratorAggregate result, validates
aggregate output, supports constructor reentry, and allocates native wrapper
handles. The constructor retains its LEAVES_ONLY constant default in reflection.
Current values from user inner iterators are cached until movement; native arrays
read live storage. Inner/subiterator access, method forwarding, clone rejection,
reflection cloneability, and uninitialized-state diagnostics are integrated.
Native frame ownership participates in object destruction and cycle collection;
frames are released deepest-first and cached values precede inner object release.
