IMPLEMENTATION AND LIMITS
fprintf and vfprintf validate the stream before the format and value arguments,
share the existing formatter, and report the formatted byte length even when a
write fails. String conversion exceptions preserve PHP's completed partial format
buffer; printing/writing occurs before propagating the pending exception. A later
format error aborts the write and chains the earlier conversion exception.
file_get_contents parses context/offset/length arguments in native order, opens
supported streams, seeks positive offsets from the start or negative offsets from
the end, and reads to EOF or the requested limit. It follows PHP's stat-based
buffer sizing and read-error behavior, including an empty string after an initial
read error, false on open/seek failure, and closing its temporary stream.
General URL/user wrappers, configurable contexts/include paths, PHP memory limits,
full stream filtering/buffering parity, and complete native metadata remain unfinished.
PHP 8.5.0 ext/standard/formatted_print.c, ext/standard/file.c,
main/streams/streams.c, native signatures, upstream PHPT, and reference execution
establish the implemented behavior.
