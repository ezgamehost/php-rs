soundex implements PHP's four-byte encoding, including the initial letter,
zero-code letters resetting duplicate handling, ignored nonletters, zero padding
and processing bytes after NUL. metaphone implements PHP's traditional phonetic
rules, initial-letter exceptions, input-letter duplicate suppression, and its
C-string termination behavior. Output limits are checked between input letters,
so X's two-character expansion can exceed the limit by one, matching PHP.
Letter classification follows the C locale; general locale changes and PHP
request memory limits remain unfinished.

Direct PHP reference comparisons match representative words, initial-letter and
consonant rules, punctuation, all alphabet letters, high bytes, interior NUL,
empty/numeric strings, limits, weak/strict argument conversion, named arguments,
Stringable input, negative-limit errors and reflection defaults.
