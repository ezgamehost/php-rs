ArrayIterator now supports native array/object backing, constructor/reinitialization,
get/set flags, rewind/valid/current/key/next/seek, getArrayCopy, count, offset access,
append/unset, and debug output. Its implemented interface metadata includes
SeekableIterator, ArrayAccess, and Countable, with native tentative return types.
Clones retain their original as backing storage but have independent cursors.
Array casts/exports use backing storage unless STD_PROP_LIST is enabled.
get_object_vars continues to report ordinary public properties. Object backing
emits PHP 8.5's deprecation, maps numeric offsets to property names, and skips
non-public slots during iteration/counting. Constructor reentry accumulates flags;
setFlags replaces the public flag bits.

Native iteration preserves raw storage references and allows foreach by reference,
including typed-property/readonly checks on backing objects. Overriding an Iterator
method switches iteration to the user-hook path and its reference restriction.
Native offset access supports nested writes and references, while direct offsetGet
returns a detached value. isset distinguishes null slots from offsetExists. Offset
key diagnostics distinguish object access, unset, and isset/empty contexts.

The native storage payload participates in object construction, clone, destructor
transfer, and trial-deletion cycle collection. Ordinary properties are released
before native backing storage. Internal mutations drop storage borrows before
running queued PHP destructors.

All 797 existing Rust tests and 57 reference-checked project PHPT pass.
Formatting, Clippy, and diff checks pass. No new custom tests or matrices added.
Direct PHP CLI comparisons match shared storage, independent clone cursors, offset
references/nested mutation, native reference iteration, null-slot queries, casts,
getArrayCopy/get_object_vars, seek failure state, offset errors, cycle counts,
destruction order, constructor reentry flags, and numeric properties on object
backing. Output and exit status match; reference diagnostic settings are
 display_errors=stderr and log_errors=0.

Implementation sources: PHP 8.5.0 ext/spl/spl_array.c, ext/spl/spl_array.h,
and ext/spl/spl_array.stub.php, with existing Zend reference/iteration machinery.

Remaining ArrayIterator work includes sorting, serialization and Serializable,
ARRAY_AS_PROPS routing, native object comparison, overloaded-object rejection,
and cursor mutation/diagnostic edge cases. RecursiveArrayIterator, ArrayObject,
generators/fibers, property hooks, complete reflection, and prior runtime gaps
remain incomplete. Unsupported PHPT sections are not counted as passes.
