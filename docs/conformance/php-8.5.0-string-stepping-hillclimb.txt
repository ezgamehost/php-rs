str_increment and str_decrement implement PHP's ASCII alphanumeric string
stepping with native argument conversion and named parameters. Each character
retains its letter case or digit class during carry and borrow. Carry past the
first character adds the appropriate prefix; decrement removes the first
character on borrow or a resulting leading zero. Empty and non-alphanumeric
strings raise ValueError. Decrement rejects all strings starting with zero and
single-letter a/A underflow, preserving the original value in its diagnostic.
Numeric-looking strings, including scientific notation, remain strings.

prefixes, leading-character removal, scientific notation, empty strings, NUL,
non-ASCII characters, punctuation, weak/strict arguments, named parameters,
