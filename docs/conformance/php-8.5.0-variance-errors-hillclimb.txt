- Direct PHP 8.5.0 probes match unresolved-type diagnostics, final and non-final
  self/static overrides, and definite signature failures alongside unresolved
  types. These failures avoid autoloading, including untyped parameter cases.
  Fatal comparisons combine stdout/stderr, normalize the leading newline,
  and disable native fatal backtraces.
- No new tests, upstream fixture changes, or dependencies.

Implementation:
- Compatibility diagnostics distinguish unavailable class dependencies from
  incompatible resolved declarations while retaining full method signatures.
- Definite type mismatches take precedence over unresolved obligations elsewhere
  in the signature and do not invoke autoloaders. Union constraints inspect each
  member independently; structurally invalid signatures remain immediate errors.
- A final class can replace an inherited static return type with its own class
  type, including self. Non-final classes retain the stricter requirement.

Remaining limits:
- Multiple delayed-obligation ordering, autoloader-exception diagnostics,
  complex intersection/union relationships, and other runtime behavior remain
  incomplete. This focused gate does not establish full PHP conformance.
