- Direct PHP 8.5.0 comparisons match literal numeric-string key lookup, 20-byte
  reference IDs, alias lifetime, final/native metadata, cloning rejection, and
  constructor-bypass rejection. IDs themselves are intentionally opaque and random.
- Constructor visibility diagnostics match native construction errors while
  explicit method calls retain the method-call diagnostic.

Implementation:
- ReflectionReference::fromArrayElement retains shared reference containers and
  directly self-referential arrays, ignoring ordinary values and unshared wrappers.
- Reference IDs hash the container identity with a lazily generated per-runtime
  random key using the existing SHA-1 implementation. Reflection objects retain
  the reference container, preserving its lifetime and identity.
- The native final class has private construction/cloning, rejects serialization
  and unserialization, and cannot bypass construction through ReflectionClass.
- Construction access errors omit the ordinary method-call label, matching PHP's
  separate constructor-access diagnostic.

Remaining limits:
- WeakReference, WeakMap, cycle collection, and other runtime features remain
  unfinished. This focused gate does not establish full PHP conformance.
