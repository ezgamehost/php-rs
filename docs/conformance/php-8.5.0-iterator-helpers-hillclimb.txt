iterator_to_array preserves array inputs or creates a reindexed list, and consumes
user iterators with optional key preservation. It keeps raw current references,
coerces keys through PHP's array-offset rules, and destroys replaced duplicate-key
values while current and key values remain retained. iterator_count accepts arrays
and Traversable objects, counts using rewind/valid/next, and does not fetch current
or key. iterator_apply accepts Traversable only, validates callback and optional
nullable args array in order, dispatches named/reference arguments with native weak
coercion, and counts callbacks including the final false result. A false callback
stops iteration without calling next. Exceptions propagate and iterators are
released on failure.

SeekableIterator, RecursiveIterator, and OuterIterator extend Iterator with PHP's
method signatures and tentative return types. Aggregate resolution rejects raw
reference returns, even when the reference contains an iterator object. Foreach
and helper key fetching detach reference-returned keys immediately.
