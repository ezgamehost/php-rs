Implementation:
- Signature checks first validate arity, references, and variadics, then compare
  contravariant parameter and covariant return type constraints.
- Unresolved method comparisons defer early binding. At declaration execution,
  compatibility checks load missing class dependencies and retry comparison.
- Class relationships recognize aliases on both sides of the comparison.
- Registration tracks pending class declarations while parent/interface loading
  runs. Variance checks can inspect their ancestry without recursively loading
  the same class. A visited set guards cyclic unlinked inheritance graphs.
  The pending registry is restored or cleared on success and error paths.

Remaining limits:
- Complex ordering among multiple delayed obligations, unavailable-type and
  autoloader-exception diagnostics, and some union/static return relationships
  remain incomplete. This focused gate does not establish full PHP conformance.
